# Chess Game with AI Bot 🤖🏆

Игра в шахматы, написанная на Python, с возможностью игры против искусственного интеллекта (нейросети).

## 🚀 Технологический стек
* **Программирование:** Python 3
* **Архитектура ИИ:** PyTorch (модель обучена в Google Colab)
* **IDE:** Visual Studio / Visual Studio Code

## 📁 Структура проекта
* `main.py` — точка входа, запуск игры.
* `board.py` / `game.py` — логика шахматной доски и правил игры.
* `bot.py` — модуль взаимодействия с ИИ-аппонентом.
* `movehandler.py` — обработка ходов.
* `chess_model_training.ipynb` — ноутбук с процессом обучения модели в Google Colab.
* `chess_bot.pth` — веса обученной нейросети.

## 🧠 О модели (AI)
Модель принимает текущее состояние доски и возвращает наилучший ход. 
* Архитектура спроектирована и обучена с использованием библиотеки **PyTorch**.
* Полный код создания датасета, архитектуры сети и процесса обучения доступен в файле `chess_model_training.ipynb`.
